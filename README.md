# 脑控小车系统 — SSVEP 3×3 频率-相位编码 BCI

基于稳态视觉诱发电位 (SSVEP) 的脑机接口 Mecanum 小车控制系统。

```
┌──────────┬──────────┬──────────┐
│  ↖ 前进左 │  ↑ 前进  │  ↗ 前进右 │   8.0 Hz   9.0 Hz  10.0 Hz
├──────────┼──────────┼──────────┤
│  ← 左转  │  ■ 停止  │  → 右转  │  11.0 Hz  12.0 Hz  13.0 Hz
├──────────┼──────────┼──────────┤
│  ↙ 后退左 │  ↓ 后退  │  ↘ 后退右 │  14.0 Hz  15.0 Hz  15.8 Hz
└──────────┴──────────┴──────────┘
        3×3 网格，9 个闪烁块，9 条小车命令
```

```
└────────────────────┴────────────────────────────────────┘
```

### 数据流

```
EEG (8ch × 250Hz)
  → 滤波器组 (8 子带, 6~80Hz)
    → FBCCA (频率-相位联合参考信号)
      → 9 维得分向量
        → 滑窗投票 (3 取 2)
          → 命令 ID (0~8)
            → 小车 TCP 指令 (可选)
```

### 关键文件

| 文件 | 作用 |
|------|------|
| `car_window_v2.py` | **主页面**：刺激画布 + 训练 + 在线 + 小车控制 |
| `ssvep_grid_canvas.py` | SSVEP 闪烁网格渲染 (Qt 原生, 正弦调制) |
| `FBCCA.py` | 解码器 (频率-相位联合编码版) |
| `acquisition.py` | EEG 数据缓冲 |
| `training_framework.py` | 训练数据加载/管理 |

## 使用流程

### 1. 连接设备

"设备控制" 页面 → 选择放大器 → 开始采集 → 看到实时波形即正常。

### 2. 训练采集

"脑控小车" 页面 → 模式选 **"训练采集"**：

1. 确认命令标签: `↖前进左,↑前进,↗前进右,←左转,■停止,→右转,↙后退左,↓后退,↘后退右`
2. 设置每类采集次数 (建议 ≥ 10)
3. 点击 **"▶ 开始"**
4. 注视绿色高亮的闪烁块，等待提示→采集→休息循环
5. 自动保存到 `saveCarData/<被试名>/`

```
训练时序: [Cue:1s] → [Stim:3s] → [Rest:0.8s] → 下一个
            绿色高亮      注视采集      短暂休息
```

### 3. 在线控制

模式选 **"在线控制"** → 点击 **"▶ 开始"**：

1. 自动用已采集数据训练 FBCCA 解码器
2. 实时解码 → 投票 → 显示当前命令
3. 可选：连接小车 → 勾选"解码输出到小车" → 命令自动驱动小车

### 4. 离线评测

```bash
python -m evaluation.offline_eval_200 --subject hc33 --kfold 5 --save
```

输出准确率 + ITR 表格。

## 算法说明

### FBCCA (默认, 无监督)

```
滤波器组 (8 子带) → 每个子带独立 CCA → 加权融合 → 9 维得分
```

**关键改进**：频率-相位联合参考信号

```python
# 标准版: 仅频率
ref = sin(2π·f·t), cos(2π·f·t)

# 本系统: 频率 + 已知相位
ref = sin(2π·f·t + h·φ), cos(2π·f·t + h·φ)
# h = 谐波次数, φ = 每个块的已知相位
```

相位采用棋盘格分配 `(row + col) % 3`，确保相邻块相位不同。

### TDCA (有监督, 更高精度)

需要训练数据 → DSP 空间滤波 + 时滞增强 → 适合数据量充足时使用。

## 小车控制协议

TCP 文本协议，4 电机 Mecanum 底盘：

```
命令格式: <左前>,<右前>,<左后>,<右后>\n

前进:   50,50,50,50    后退:  -50,-50,-50,-50
左转:  -40,40,-40,40    右转:   40,-40,40,-40
停止:    0, 0, 0, 0
斜向:  Mecanum 组合 (如前进左: 30,60,60,30)
```

默认 IP: `10.186.179.92:65432` (界面可修改)

## 常见问题

**Q: 启动报错 "No module named 'models'"**
> 必须从 `Visual_BCI_App` 目录启动: `cd Visual_BCI_App && python main.py`

**Q: 刺激不显示**
> 检查模式是否选择了"训练采集"或"在线控制"，空闲模式不闪烁

**Q: 解码准确率低**
> 增加每类训练次数 (≥15)，延长刺激时长 (4s)，尝试 TDCA 模型

**Q: 如何改命令数**
> 修改 `config.yaml` 中的 `sti_lst` (删除不需要的频率) 和 `ssvep_grid_rows/cols`

**Q: 如何添加自定义标签**
> 在"命令标签"输入框中用逗号分隔，如 `前进,后退,左转,停止,右转`
